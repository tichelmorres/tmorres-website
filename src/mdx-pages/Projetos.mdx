## Soluções para o _"CSES Problem Set"_ em C

O      conjunto      de      problemas      ++[CSES      Problem
Set](https://cses.fi/problemset/)++   foi   criado   por   Antti
Laaksonen   ---   autor   do   conhecido   livro   _"Competitive
Programmer's  Handbook"_  --- usando o sistema de avaliação CSES
(Code Submission Evaluation System).  Esse é um dos conjuntos de
problemas  mais  conhecidos no campo da programação competitiva,
tanto  entre  iniciantes  quanto competidores renomados, e cobre
400  problemas  seletos  sobre  **algoritmos** e **estruturas de
dados**.

Meu  repositório  contém  soluções escritas manualmente em C, em
contraste  com o convencional C++ usado em programação dinâmica,
como  forma  de  desafiar  as minhas habilidades lógicas e obter
melhor  entendimento  sobre  o  funcionamento  dos computadores.
Nenhuma das soluções foi gerada por/com auxílio de IA.

<Highlight tint>
++[Soluções no Github](https://github.com/tichelmorres/cses-problem-set-c.git)++
</Highlight>

## Bot de figurinhas para o Discord

O **Sticker Discord Bot** (nome não muito criativo, eu sei) é um
bot  desenvolvido  para  o Discord que busca viabilizar o uso de
quaisquer  <Highlight affect="wobbly">figurinhas</Highlight> sem
a necessidade de pagar por um serviço premium como o Nitro.  Ele
funciona  através de comandos para receber, escanear e registrar
imagens,  vídeos  e  gifs como figurinhas através de uma base de
dados contruída localmente em um servidor.

## Grass

<Align to="center">
  <Rescale width={768} height={432}>
    <Imagetic path="vid/projects/grass/harmonograph.mp4"

GRASS,  ou  **GRaphical  SimulationS**, é uma biblioteca gráfica
multi-uso desenvolvida em C.  O Grass oferece interface de baixo
nível com alta capacidade de customização para a renderização de
<Highlight affect="wobbly">simulações gráficas</Highlight>.

O   vídeo   a   cima   demonstra  o  movimento  pendular  de  um
++[harmonógrafo](https://pt.wikipedia.org/wiki/Harmon%C3%B3grafo)++,
aparato  científico  usado para construir e estudar ++[curvas de
Lissajous](https://es.wikipedia.org/wiki/Curva_de_Lissajous)++.

## Flec
FLEC,  ou **FLac Editor in C** é uma ferramenta TUI desenvolvida
para  editar  metadados de arquivos de áudio FLAC.  Voltada para
edição   local   de   músicas,   a   ferramenta   conta  com  as
funcionalidades  básicas necessárias para customizar dados nesse
tipo  de  arquivo:  nome  da  música,  álbum,  artista e data de
lançamento.

FLEC  conta  com  integração ao FZF, que permite navegar através
dos diretórios rapidamente.  Além disso, pode modificar um mesmo
metadado  através  de  todos  os  arquivos  em um diretório (Ex:
editar o nome do álbum de todas as músicas em uma mesma pasta).

Para mais informações, consulte o repositório.

<Highlight tint>
++[Repositório do FLEC no Github](https://github.com/tichelmorres/flec.git)++

## Echidna Emacs
Echidna   é   um  esquema  de  cores  originalmente  criado  por
++[2besita](https://github.com/2besita/)++.   Meu  repositório é
um  porte  desse  esquema  para  GNU Emacs.  O fundo escuro e as
cores  de baixo contraste facilitam a leitura mesmo em monitores
mais simples, o que é ideal para mim.

*Curiosidade:  é  o  mesmo  esquema de cores que usei neste site
para o tema escuro.*
